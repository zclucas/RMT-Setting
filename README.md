## ⚙️ RMT 配置下载与导入
1. 在仓库中找到所需的 `.rmt` 配置文件并下载到本地  
2. 运行 **若梦兔（RMT）** 软件  
3. 点击右上角的 **配置管理 → 导入配置**  
4. 选择下载的 `.rmt` 文件即可完成导入 
✅ 配置导入后，可以查看 **使用说明**，了解配置的使用细节。 

---

## ☁️ RMT 配置共享与上传
1. 配置操作下 **使用说明** 完善信息
2. 配置操作下 **导出配置** 导出`.rmt`文件
3. 仓库配置下 **共享上传** 上传文件
4. **群主或管理员** 审核后会同步到共享配置仓库中
