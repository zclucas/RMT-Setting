## ⚙️ How to Download & Import RMT Configurations
1. Find the `.rmt` configuration file you need in the repository and download it.  
2. Run **RMT (Ruomeng Rabbit)** software.  
3. Click **Configuration Management → Import Configuration** in the top-right corner.  
4. Select the downloaded `.rmt` file to import.  

✅ After importing, you can check the **Usage Instructions** to learn detailed usage of the configuration.

---

## ☁️ How to Share & Upload RMT Configurations
1. Complete the **Usage Instructions** for your configuration.  
2. Export the `.rmt` file under **Export Configuration**.  
3. Upload the file under the repository's **Shared Configurations** section.  
4. **Group owners or administrators** will review and sync it to the shared configuration repository.
